what is not drawn
  • The frozen U-Net's inside. It has skip connections; here it is one grey box, and the miniature stands in a formula for it.
  • Skip connections in the checker: PixelHead has none, so none are drawn.
  • The three stem convolutions and c1 become one convolution with one window per half; c2 is left out; the MLP's hidden layer of 256 and its SiLU are left out; 16 time features become 2.
  • Adam at 0.001 on 256 canvases for 4,000 updates becomes one plain step of 0.05 on two canvases.
  • Count's other three kinds of canvas (overlaid, same half, single).
  • Real maps, logits and gradients on these canvases: the split run never saved its two heads, so this needs one GPU job.
  • The real count checker's score at each timestep: split.json was not written when the ladder was built, so the noise frame plots the miniature's score.
  • The push uses the miniature's starting weights, not trained ones.
how to read the page
  • Blue: pixels and time. Green: trained units. Red: the logit. Orange: anything flowing backward. Grey: frozen. Purple: count. Teal: identity.
  • A circle holds the value at that node. A number on a line is that connection's weight.
  • The right arrow key or next moves one idea on. Play replays the current pass, step moves it one layer, and sweep noise runs the 16 timesteps.
